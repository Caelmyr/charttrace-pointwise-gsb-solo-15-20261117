# ChartTrace 图表曲线采集

运行 `docker compose up --build -d` 后打开 http://localhost:18918。数据在独立命名卷 solo18-charttrace-data 中。也可 Python 3.11/3.12 安装 requirements.txt 后运行 `python3 app.py`，数据在 CHARTTRACE_DATA_DIR。

主页面从合成示范开始：三点标定斜轴与数据范围、线性/对数坐标、上传PNG/JPEG、吸取颜色、连续性/容差调节、多曲线、手动像素锚点、全局路径追踪、缺口分段采样、图像叠加核对、CSV与ZIP交付、命名版本恢复和固定历史结果。坐标原点与端点使用源图像素，校对点也固定在源图。更改标定重新解释数据而不移动校对点。短缺口可辅助追踪，但不作为观测输出。对数轴均匀采样指对数比例空间。

**可继续编辑的交付包**：在“可编辑交付包与版本”中可选择带走当前固定结果（或尚未提取的当前编辑状态），并勾选若干命名版本。导出包 `chart-editable.zip` 内包含本次提取对应的原图（按内容哈希只存一份，共用同一张图的版本不重复）、标定、各曲线的追踪设置与手动校对点、命名版本，以及原来的提取结果（数据、`overlay.png`、`data.csv`），因此换一台电脑在 ChartTrace 点击“导入可编辑包”后即可接着校对、重提，并继续查看包里原来那份结果。结果按其提取时的状态导出，不会被工程当前的新设置替换；导入总会新建工程并使用不冲突的名称，不覆盖本地同名工程。包根目录仍保留 `data.csv`、`extraction.json`、`overlay.png`，与原“图像与数据包”兼容；结果下载区也保留“可继续编辑包”入口。缺少原图、被截断或校验失败的包会给出具体原因。CSV 下载、图像与数据包下载和查看历史结果的方式保持不变。

输入最长边4096；每工程最多8条单值曲线、每条200校对点、1200×800追踪网格和2000采样点。适合颜色可分辨的连续单值曲线，不自动识别文字刻度、不保证处理自交曲线或同色多曲线。结果是图像采集近似，须核对。透明图像在可见白底中取证，透明区不会成为颜色依据。演示为合成图，不能当作实验观测。

`/prepare` 保留自有 image_lab 图像准备工作台，支持序列导入、配准、多帧处理、质量检测、色彩/曝光、区域与导出，供曲线采集前整理图像。image_lab 与其静态资源原样复用自本工作区 solo_17 的自有准备模块；ChartTrace 的坐标、追踪、持久化、数据交付及主界面为本产品新增。继承模块不是第三方代码。
