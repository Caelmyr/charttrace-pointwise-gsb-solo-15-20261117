# ChartTrace 图表曲线采集

运行 `docker compose up --build -d` 后打开 http://localhost:18918。数据在独立命名卷 solo18-charttrace-data 中。也可 Python 3.11/3.12 安装 requirements.txt 后运行 `python3 app.py`，数据在 CHARTTRACE_DATA_DIR。

主页面从合成示范开始：三点标定斜轴与数据范围、线性/对数坐标、上传PNG/JPEG、吸取颜色、连续性/容差调节、多曲线、手动像素锚点、全局路径追踪、缺口分段采样、图像叠加核对、CSV与ZIP交付、命名版本恢复和固定历史结果。坐标原点与端点使用源图像素，校对点也固定在源图。更改标定重新解释数据而不移动校对点。短缺口可辅助追踪，但不作为观测输出。对数轴均匀采样指对数比例空间。

同一张原图可划出多个命名面板，每个面板有自己的矩形区域、坐标标定、曲线与校对点。原图总览用于查看和拖动面板矩形，单面板操作用于在该面板内点标定点、吸色和加校对点；两者可随时切换。面板矩形就是取样边界，追踪只读取本面板像素。面板矩形允许重叠（例如共用的图例区），重叠像素默认双方都不取样，因此不会把相邻面板的曲线采进来；某个面板可显式声明“本面板取样”来认领重叠区。移动或缩放面板时，其标定轴按同一比例跟随移动，校对点留在源图像素不动，界面会标出仍适用、落在重叠区不取样、已在面板外的校对点。已有提取结果按面板逐一标记“仍适用 / 标定已变 / 面板已删”，数值仍是提取当时的值。一次提取覆盖全部面板：CSV 首列保留面板归属，ZIP 另附每个面板单独的 CSV 与记录区域、标定和曲线清单的 panels.json。命名版本与历史下载同样按各面板当时的标定保存。

输入最长边4096；每工程最多8个面板、每面板8条单值曲线、每条200校对点、1200×800追踪网格和2000采样点。适合颜色可分辨的连续单值曲线，不自动识别文字刻度、不保证处理自交曲线或同色多曲线。结果是图像采集近似，须核对。透明图像在可见白底中取证，透明区不会成为颜色依据。演示为合成图，不能当作实验观测。

旧版单面板工程（顶层的 calibration 与 series）在首次打开时自动迁移为一个覆盖整幅图的面板，标定与曲线原样保留，因此仍可直接打开；其历史结果也仍可下载。原单面板按钮保留，新建后同样是一个整幅图面板。

`/prepare` 保留自有 image_lab 图像准备工作台，支持序列导入、配准、多帧处理、质量检测、色彩/曝光、区域与导出，供曲线采集前整理图像。image_lab 与其静态资源原样复用自本工作区 solo_17 的自有准备模块；ChartTrace 的坐标、追踪、持久化、数据交付及主界面为本产品新增。继承模块不是第三方代码。
